# 검색 품질과 기억 품질의 근본적 개선

## 의도

검색 품질과 기억 품질을 제품 수준으로 올린다. 숫자를 맞추는 것이 아니라 손실 기록이 가리키는 원인을 고친다. 검색은 질문의 언어가 아니라 내용으로 순위가 정해져야 하고, 기억은 쓰는 순간부터 찾기 쉬워야 한다.

출발점: spec `docs/specs/2026-11-11-search-and-memory-quality-2/spec.md`, 손실 보고서 `docs/design/reports/2026-11-search-loss-classification.md`.

## 목표

spec 2.1의 목표1~11. 검색 목표는 질문 하나만 넣어서 잰다.

## 완료 기준

1. 고른 방안을 비교한 근거가 보고서에 있고, 사용자가 승인했다.
2. 시험용 문항으로 한 번 잰 결과가 목표1~11을 넘는다.
3. 원인 자체가 줄었다는 측정이 있다. 원인이 그대로인데 숫자만 넘은 것은 완료가 아니다.

## 하지 말아야 할 것

1. 특정 페이지 점수 조정, 시험용 문항으로 조정, 목표를 맞추려는 라벨 변경.
2. 도구 안 LLM 호출. vault-graph가 Vault 내용을 만들어 쓰는 것.
3. 층1 질문 원문이나 회사 Vault 내용을 저장소나 외부로 내보내는 것.
4. 사용자 확인 없이 모델 내려받기, 기본 모델 교체, spec 변경, 실제 Vault에 쓰기.
