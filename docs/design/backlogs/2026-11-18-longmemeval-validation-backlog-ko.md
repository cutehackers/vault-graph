## 3. 일반

### LME-01 사실 키와 날짜 범위의 효과를 충분한 표본으로 잰다
- [ ] proposed · 측정 · retrieval, facts
- 문제: [확인] 사실 키는 40문항에서 가중치 0.5일 때 +1, 1.0일 때 +5, 2.0일 때 +8문항이었고 나빠진 문항은 없었다(research X26). [확인] 이 40문항은 대표 표본이 아니고, 논문은 질문마다 대화가 열 배인 LongMemEval_M에서 효과를 보였다(X31). [확인] 날짜 범위는 사건 날짜로 고친 뒤 범위가 붙는 10문항에서 1문항을 지켰고 1문항을 잃었다.
- 영향: 사실 추출은 기본으로 켜져 세션마다 Claude Code 사용량을 쓰는데, 그만한 검색 이득이 있는지 모른다.
- 방향: LongMemEval_S의 multi-session·temporal-reasoning 전체(약 250문항, 겹치는 대화를 빼면 약 1만 세션)에서 사실을 뽑아, 사실 없음·가중치 1.0·2.0과 날짜 범위 기본·엄격 모드를 같은 작업 공간에서 비교한다. 가중치는 개발용 절반으로 고르고 시험용 절반에서 한 번만 확인한다. 가능하면 LongMemEval_M 일부로 논문 조건도 본다. Claude 약 18시간 또는 로컬 Qwen(사고 단계 끔, 세션당 약 14초).
- 완료: 보고서에 문항 수, 유형별 recall_all@5, 나빠진 문항 수, 사용량이 있고, 그 결과로 사실 추출 기본값(켜짐 유지 여부)과 가중치가 정해졌다.
- 출처: spec 2026-11-16 D23 측정과 사용자 결정(2026-11-18, 옵션3)
