# 측정 A-19: 바뀐 문서 단위 그래프 갱신 (2026-11-06)

spec 2026-11-05-session-memory-indexing, 작업 #35. 코드: 그래프 증분(`5abc905`)과 그 앞의 색인 변경 전부.

## 방법

- dry-run: 실제 vault-graph Vault를 작업용 폴더에 복사하고 이 브랜치로 `--no-vector` 색인을 만든 뒤, `wiki/` 페이지 0, 1, 5개에 문단을 더하고 `vg index --dry-run`의 그래프 upsert 수를 읽었다. 실제 Vault는 바꾸지 않았다.
- 고정 비용: 실제 Graph Home의 복사본(경로 정보만 복사본에 맞춤)을 이 브랜치로 한 번 색인한 뒤, 바뀐 파일 없이 `vg index --vault-id vault-graph`를 벡터 포함으로 돌렸다.

## 결과

|---|---|---|---|
| 0 | 0 | 0 | 0 |
| 1 | 49 | 68 | 7 |
| 5 | 80 | 128 | 43 |

이 변경 전에는 바뀐 문서 수와 상관없이 그래프 엔티티 약 26,000개와 근거 62,641행을 run마다 다시 썼다(spec 원인4, 작업 #30 보고).

| 바뀐 파일 없는 `vg index --vault-id vault-graph` | 시간 | 최대 RSS |
|---|---|---|

## 판단

- A-19 측정 조건 "엔티티 upsert 수가 바뀐 문서 수에 비례한다"를 충족한다. 0개면 0이고, 링크 상대의 근거만 함께 다시 만든다.
- 증분 결과와 full run이 같은지는 `tests/test_graph_incremental_equivalence.py` 12개가 링크 추가·수신·family 변경·삭제·세션 파트 추가에서 확인한다.
- 바뀐 파일이 없는 run의 고정 비용은 크기·수정 시각 사전 검사(#4), 벡터 목록 표(#9), 그래프 증분(#30)으로 16.8초에서 3.9초로 줄었다.
