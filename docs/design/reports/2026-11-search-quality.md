# 검색 품질 단계별 측정 (2026-11-07)

spec 2026-11-05-session-memory-indexing §10. 단계마다 같은 평가 세트를 같은 방법으로 쟀다.

## 방법

- 평가 세트(spec §10.1, 저장소 밖):
  - wiki 35문항: 제목 그대로 20, 의역 7, 결정 5, 방법 3. 정답은 페이지 경로 하나.
  - 세션 14문항: 의역 9, 결정 4, 방법 1. 정답은 교환 줄 범위.
- Vault는 실제 personal Vault와 실제 vault-graph Vault의 복사본이다. 실제 Vault와 실제 Graph Home은 바꾸지 않았다.
- 단계마다 복사본으로 Graph Home을 새로 만들었다(`vg init`, `vg index`).
- 질의: `tests/benchmarks/measure_session_recall.py`, 결과 20개. wiki는 `--vault-id personal`, 세션은 `--vault-id vault-graph --mode evidence`.
- 모드: knowledge는 기본 검색이다. all은 모든 역할을 찾는다.
- 수치는 recall@5, recall@10, MRR이다. 정답이 상위 20 밖이면 MRR은 0으로 센다.

## 단계별로 바뀐 것

1. 단계A(색인 그대로, 원인1·2·3·4·6)
   - 기본 knowledge 모드에 `wiki/sources/` 페이지를 넣고 가중치 0.8을 준다.
   - 문서 하나가 결과 하나다.
   - 직접 대체 관계만 접는다.
   - Vault 사이 순위를 한 줄로 합친다.
   - 한국어 조사를 뗀다.
   - 제목 질문이 0.55에서 1.00이 되었다. 문서마다 결과 하나라 상위 5개가 모두 다른 문서다.
2. 단계C(조각 나누기, 원인7·8)
   - wiki 페이지를 160단어 창과 페이지 카드로 나눈다.
   - 템플릿 절은 벡터에서 뺀다.
   - 세션 창을 96단어로 줄인다.
   - 의역 질문이 0.29에서 0.57이 되었다. 대신 제목 질문 MRR이 0.84에서 0.76으로 내려갔다. 페이지 카드와 본문 창이 서로 비슷한 점수로 경쟁했기 때문이다.
3. 단계B(키워드 표, 원인5)
   - title·aliases 열 가중치 10, path 5, 나머지 1을 준다.
   - frontmatter 열은 tags, summary, 교환 메타만 담는다.
   - 제목 일치 신호를 더한다.
   - 제목 질문 MRR이 0.975가 되었고 다른 값은 그대로다. 색인 시간은 wiki 44.9초에서 45.3초로 거의 같다.
   - 옛 v2 Graph Home에 `vg index`를 돌리면 1.8초 안에 키워드 표만 다시 채운다.

## 수용 기준(spec §10.4)

| 단계 | 기준 | 결과 |

| A | wiki 기본 모드 recall@5와 MRR이 기준선보다 높다 | 0.43→0.74, 0.38→0.59. 충족 |

## 세션 창 크기 재확인

단계A·B·C를 모두 적용한 HEAD에서 창 크기만 바꿔 다시 쟀다.

| 창 | recall@5 | recall@10 | MRR | 512 모델 토큰 초과 창 |
|---|---|---|---|---|
| 160단어 | 0.71 | 0.71 | 0.40 | 608개 |
| 96단어 | 0.64 | 0.71 | 0.50 | 55개 |

recall@5 차이는 14문항 중 1문항이다. 96단어는 정답을 더 위에 두고 목표6(512 초과 1% 이하)을 지킨다. 96단어로 둔다.

## 넣지 않은 시도

all 모드의 결정·방법 질문 8개는 모든 단계에서 0이다. 7개는 정답 페이지가 상위 20 밖이다. knowledge 모드에서는 같은 질문의 정답이 3~10위다.

- all 모드 상위에는 같은 주제의 원문(`raw/sources/`), spec, 사용 문서, 점검 보고서가 온다. 결정 페이지를 만든 원문이 많다.
- 이 Vault의 all 모드 조각 3,492개 중 정리 페이지 조각은 286개(8%)다. 원문은 문서당 35개, 운영 문서는 45개 조각이다.

두 가지를 재 보았다.
1. all 모드에도 역할 가중치(정리 1.0, source·원문 0.8, 나머지 0.6)를 준다. 결정·방법은 0 그대로이고 MRR이 0.616에서 0.603으로 내려갔다.
2. 결과 단위마다 후보 조각을 3개까지만 둔다. 결정·방법은 0 그대로다. 세션 recall@10은 0.71에서 0.86으로 올랐지만 MRR이 0.50에서 0.46으로 내려갔다. wiki knowledge recall@10도 0.83에서 0.80으로 내려갔다.

둘 다 넣지 않았다. all 모드는 원문을 함께 보려고 고르는 모드다. 정리 페이지를 찾는 질문은 기본 knowledge 모드가 답한다.
