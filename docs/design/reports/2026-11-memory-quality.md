# 측정 A-28: 기억 품질 지표와 S12 진행 판정 (2026-11-06)

spec 2026-11-05-session-memory-indexing, 작업 #40. 도구: `tests/benchmarks/measure_memory_recall.py`(`35160b2`). 코드: `8beea22`까지.

## 방법

- 실제 Graph Home의 복사본을 이 브랜치로 다시 색인한 뒤(모든 Vault, 세션은 v1 교환 조각기) 그 복사본으로 쟀다. 측정이 회상 사용 기록을 남기므로 실제 Graph Home에는 돌리지 않았다(폐기 후보 (2)가 측정 기록에 끌려가지 않게).
- vault-map은 이 Mac의 실제 파일이다. 연결 프로젝트 다섯(vault-graph, bake, sgp-981-app, vault-builder, 981park-flutter-app)마다 세션 시작 회상을 한 번 돌렸다.
- 질문 세트는 **대리 세트**다. spec은 사람이 만든 질문 40개 안팎을 요구한다. 이번에는 프로젝트마다 정보 추출 1개와 답하지 않기 1개, 프로젝트 섞임 1개로 모두 11개다. 이 Mac의 프로젝트 Vault 다섯은 모두 같은 템플릿 페이지 17쪽만 있고, 실제 결정은 personal Vault에 있다. 그래서 질문 세트로 낼 수 있는 결론은 적다. 판정 지표 1·2는 질문과 상관없이 회상 출력과 색인만으로 계산한다.

## 판단

- spec §4.4.11 단계4의 조건(지표1·2가 0)을 충족한다. 단계5(S12: brief와 대체 경로 제거 확인)로 진행할 수 있다.
- 지표5가 크다. vg 정리 흐름이 아직 한 번도 돌지 않았기 때문이다. 첫 "기억 정리해"에서 줄어드는지 본다(작업 #38).
