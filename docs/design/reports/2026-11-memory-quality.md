## 방법

- 실제 Graph Home의 복사본을 이 브랜치로 다시 색인한 뒤(모든 Vault, 세션은 v1 교환 조각기) 그 복사본으로 쟀다. 측정이 회상 사용 기록을 남기므로 실제 Graph Home에는 돌리지 않았다(폐기 후보 (2)가 측정 기록에 끌려가지 않게).
- vault-map은 이 Mac의 실제 파일이다. 연결 프로젝트 다섯(vault-graph, bake, sgp-981-app, vault-builder, 981park-flutter-app)마다 세션 시작 회상을 한 번 돌렸다.
- 질문 세트는 **대리 세트**다. spec은 사람이 만든 질문 40개 안팎을 요구한다. 이번에는 프로젝트마다 정보 추출 1개와 답하지 않기 1개, 프로젝트 섞임 1개로 모두 11개다. 이 Mac의 프로젝트 Vault 다섯은 모두 같은 템플릿 페이지 17쪽만 있고, 실제 결정은 personal Vault에 있다. 그래서 질문 세트로 낼 수 있는 결론은 적다. 판정 지표 1·2는 질문과 상관없이 회상 출력과 색인만으로 계산한다.

## 본 질문 세트로 다시 잰 값 (2026-11-07)

### 질문 세트

사용자가 질문 세트를 별도 에이전트가 고르도록 정했다(2026-11-07). 측정할 회상과 검색을 쓰지 않고 고르게 해서 측정 대상에 맞춘 세트가 되지 않게 하려는 것이다.

- 고른 에이전트는 Vault의 wiki 페이지와 세션 파일만 직접 읽었다. vg, MCP, 검색 도구는 쓰지 않았다.
- 질문 42개. 프로젝트별로 vault-graph 17, sgp-981-app 16, bake 9.
- 축별: 여러 세션 추론 8, 시간 추론 7, 정보 추출 6, 대체된 결정 사용 6, 지식 갱신 5, 답하지 않기 5, 프로젝트 섞임 5.
- 프로젝트 Vault는 모두 같은 시작 페이지 17쪽만 있다. 실제 지식은 personal Vault에 있어서 정답은 대부분 `personal:wiki/...`다.
- 프로젝트 섞임 질문은 시작 페이지를 정답으로 쓴다. 이 페이지는 프로젝트 Vault와 personal에 같은 내용으로 있다. personal은 모든 프로젝트에 연결되어 있으므로 두 사본을 모두 정답으로 받았다.
- 질문 원문은 저장소 밖에만 있다.

### 방법

- 실제 Graph Home의 복사본을 이 브랜치(`28e05bd`)로 모든 Vault에 대해 다시 색인했다. Vault는 읽기만 했다.
- 실제 Graph Home의 회상 사용 기록을 복사본에 복사해 지표3에 썼다.
- vault-map은 이 Mac의 실제 파일이다.
